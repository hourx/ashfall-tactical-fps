Ashfall — a round-based tactical FPS in three.js. A water-treatment plant at dusk: two bomb sites, three lanes, and short rounds decided by elimination or by the charge. Attackers plant, defenders hold and defuse, and money between rounds buys a pistol, an SMG, a rifle, a frag or armour.

## Run it

```sh
# grade the entry the way the bounty's gate does
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

# or play the game: any static server over game/
npx serve game
```
